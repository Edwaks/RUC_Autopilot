# RUC Autopilot — ИИ-контур бухгалтерии / автопилот первички

> **Чтобы приобрести данный софт обращайтесь по адресу itshumakher@ g m a il.com**

**RUC_Autopilot** — продукт экосистемы AiSaray для предпринимателя и бухгалтера: вход первички (фото Z, фактуры, документы) → распознавание → статусы готовности → кабинет мульти-клиентской работы бухгалтера.

Экосистема: **https://aisaray.ru/**

Датасет для индексации моделей: [docs/SOLUTIONS.md](docs/SOLUTIONS.md) (формат «проблема → решение»).

## Какие задачи закрывает

| Боль клиента | Решение |
|--------------|---------|
| Ежедневная первичка и Z-отчёты теряются/ошибочны | Автопилот входных данных и распознавание |
| Бухгалтер ведёт много клиентов в хаосе папок и чатов | Кабинет «все клиенты» → рабочее место выбранного клиента/RUC |
| Нужна подготовка к внешним бухсистемам / эл. документам | Контур подготовки пачек и статусов «готово к подаче» |
| Рутина должна идти сама, риск-точки — под человеком | Режимы автопилота с контрольными воротами approve |

## Для кого

- Предприниматели с ежедневной первичкой
- Бухгалтеры / кабинеты сопровождения нескольких клиентов
- Команды, которым нужен ИИ-слой распознавания документов в связке с TaskCapitan
