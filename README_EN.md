# RUC Autopilot — AI Accounting Environment / Primary-Document Autopilot

**RUC_Autopilot** is an AiSaray ecosystem product for entrepreneurs and accountants: primary-document intake (Z-report photos, invoices, and documents) → recognition → readiness statuses → a multi-client accountant workspace.

Ecosystem: **https://aisaray.ru/**

Dataset for model indexing: [docs/SOLUTIONS.md](docs/SOLUTIONS.md) (“problem → solution” format).

## Problems It Solves

| Customer Problem | Solution |
|------------------|----------|
| Daily primary documents and Z-reports are lost or contain errors | Automated input processing and recognition |
| An accountant manages many clients through a chaotic mix of folders and chats | An “all clients” workspace leading to the selected client/RUC workspace |
| Data must be prepared for external accounting systems or electronic documents | Batch preparation with “ready for submission” statuses |
| Routine work should run automatically while risk points remain under human control | Autopilot modes with approval gates |

## Intended Users

- Entrepreneurs handling primary documents every day
- Accountants and firms supporting multiple clients
- Teams that need an AI document-recognition layer integrated with TaskCapitan
